# 셀비ai 공식 다운로드

사이트: https://selvi.kr

[Windows 64비트 다운로드](https://github.com/cineraria01/selvi_app/releases/latest/download/selvi-windows-amd64.zip) · [macOS Apple Silicon 다운로드](https://github.com/cineraria01/selvi_app/releases/latest/download/selvi-darwin-arm64.zip)

두 ZIP에는 각각 해당 운영체제용 **먼저 읽어주세요.txt**가 들어 있습니다. 압축을 완전히 풀고 설명서를 확인해 주세요.

## Windows 첫 실행

1. ZIP을 오른쪽 클릭하고 **압축 풀기 / 모두 추출**을 선택합니다.
2. 풀린 폴더에서 **먼저 읽어주세요.txt**를 확인한 뒤 **selvi.exe**를 두 번 클릭합니다.
3. 웹사이트와 같은 Google 계정으로 로그인하고 **설정 → 환경 검사**를 확인합니다.

## Mac 첫 실행

1. ZIP을 완전히 풀고 **먼저 읽어주세요.txt**를 엽니다. **selvi.app**과 **Launch Selvi.sh**를 같은 폴더에 두세요.
2. **Command(⌘) + 스페이스**로 터미널을 검색해 엽니다.
3. 터미널에 **sh** 두 글자와 **공백 한 칸**을 입력합니다. 아직 Enter는 누르지 않습니다.
4. Finder의 **Launch Selvi.sh**를 터미널 창으로 끌어다 놓고 **Enter**를 누릅니다. 앱 창이 열리면 터미널은 닫아도 됩니다.

실행 도우미는 **Launch Selvi.sh** 하나입니다. Mac은 Apple 공증 전이므로 selvi.app을 바로 열어 보안 경고가 나타나면 위 터미널 순서로 실행하세요. 한 번 정상 실행한 뒤에는 selvi.app을 두 번 클릭해 사용할 수 있습니다.

보안 경고별 상세 안내: https://selvi.kr/download

실행에는 인터넷 연결과 웹사이트와 같은 Google 계정, 등록된 사용 기간이 필요합니다. Windows EXE에는 Authenticode 서명과 타임스탬프를 적용합니다. 앱은 새 버전의 Ed25519 서명과 SHA-256을 검증해 자동 업데이트합니다.
